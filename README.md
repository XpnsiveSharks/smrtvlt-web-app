# 🔐 SmartVault

SmartVault is a high-fidelity MVP IoT platform designed to manage and secure ESP32-powered smart vault devices.  
It provides real-time monitoring, remote control, role-based access management, and detailed security auditing through a modern web dashboard and backend API.

This project serves as a **production-oriented MVP** and **portfolio-grade system** that demonstrates clean architecture, scalable design, and security-first thinking.

---

## 🚀 Features

### Core (MVP)
- Real-time device status monitoring (online/offline, battery, signal)
- Remote lock / unlock commands
- Device provisioning and lifecycle management
- Role-based access control (Owner, Admin, Editor, Viewer)
- Access and security audit logs
- Dashboard with system overview and alerts

### Planned / Future
- OTA firmware updates
- WebSocket-based real-time telemetry
- Device health analytics
- Tamper detection workflows
- Mobile companion app
- Hardware-backed authentication
